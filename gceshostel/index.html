GCES Hostel

Institutional hostel operations platform serving 1,200 daily active students. Built with multi-module Kotlin, distributed PostgreSQL transaction locks via ShedLock, and sub-100ms API latency protected by Bucket4j rate limiting.

Architecture Multi-module separation across :app, :common, and :server with Spring Boot 3.5 as source of truth for attendance, occupancy, and mess forecasting.
Concurrency ShedLock JDBC prevents duplicate 00:00 meal rollovers across backend instances while Bucket4j smooths peak dining-window spikes.
Client UI Native Jetpack Compose dashboard supporting four selectable themes and instant offline-resilient reads.
